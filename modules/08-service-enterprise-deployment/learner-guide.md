# Learner Guide

## What you will learn

You will learn how Power BI content moves from Desktop/PBIP authoring into governed Service deployment. You will publish content, configure refresh, review gateway requirements, create App distribution, and understand shared semantic model patterns.

## Scenario

Contoso Advanced Manufacturing has built a reusable Power BI solution and now needs to deploy it for business users with clear ownership, refresh, permissions, and promotion controls.

## Prerequisites

- Power BI Service access.
- Workspace permission for labs or instructor-led demo.
- PBIP report/model from earlier modules.
- Basic understanding of permissions and refresh.

## Azure Government readiness

Core workspace, publishing, refresh, and App distribution concepts are **Gov-ready**, but tenant policy still applies. App audiences, deployment pipelines, gateways, and cloud connections are **Verify for Gov**.

## Power BI project format

Source artifacts should remain PBIP projects in git. PBIX files may be generated from PBIP later for convenience, but PBIX is not the source of record.

## Tasks

1. Review workspace setup.
2. Publish the report and semantic model.
3. Configure scheduled refresh and credentials.
4. Review gateway-backed refresh.
5. Create or review shared semantic model and thin report pattern.
6. Package content as an App.
7. Review optional App audiences and deployment pipelines.
8. Apply endorsement governance checklist.

## Validate your work

Your completed work should include:

- Workspace role assignment notes.
- Published report and semantic model or instructor demo evidence.
- Refresh configuration notes.
- Gateway requirements notes.
- App distribution notes.
- Shared semantic model/Build permission notes.
- Gov validation notes for optional features.
