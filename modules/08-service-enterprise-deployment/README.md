# Module 8: Power BI Service Enterprise Deployment

## Module summary

This module teaches learners how to publish, govern, refresh, and distribute Power BI content in the Service. It covers workspace structure, workspace roles, Apps, semantic model refresh, gateways, shared semantic models, thin reports, endorsement, App audiences, and deployment pipelines.

## Learning objectives

By the end of this module, learners will be able to:

- Design workspace patterns for development, test, and production.
- Explain workspace roles and their security implications.
- Publish a PBIP-built report and semantic model to the Service.
- Configure scheduled refresh and data source credentials.
- Explain gateway-backed refresh and cloud connection considerations.
- Create thin reports from shared semantic models.
- Package content as a Power BI App.
- Explain endorsement with Promoted and Certified content.
- Identify Azure Government validation needs for App audiences, deployment pipelines, gateways, and cloud connections.
