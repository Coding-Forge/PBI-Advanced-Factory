# Learner Guide

## What you will learn

You will learn how to turn a functional Power BI report into an interactive user experience that supports different audiences, guides analysis, and remains accessible.

## Scenario

Contoso Advanced Manufacturing wants one report experience that serves executives, analysts, and operational managers. Executives need summary trends, analysts need drill paths, and operational users need detail and exceptions.

## Prerequisites

- Power BI Desktop
- A PBIP report using the Module 1 model and Module 2 measures
- Basic report authoring experience

## Azure Government readiness

The required labs are **Gov-ready** because they use Power BI Desktop report features. Personalized visuals and AI visuals are **Verify for Gov** or **Commercial-focused** and should be optional unless validated in the customer tenant.

## Power BI project format

Save report work as a PBIP project. PBIP is the source-controlled format for this workshop. PBIX can be generated from PBIP later if a packaged Desktop file is needed.

## Tasks

1. Create audience-specific report pages.
2. Add drillthrough from summary to detail.
3. Create report page tooltips.
4. Add bookmarks and buttons.
5. Add dynamic navigation.
6. Apply conditional formatting.
7. Create a mobile layout.
8. Run an accessibility review.

## Validate your work

Your completed report should include:

- Executive summary page.
- Analyst exploration page.
- Detail drillthrough page.
- Tooltip page.
- Bookmark-driven guided interaction.
- Conditional formatting with documented meaning.
- Mobile layout.
- Accessibility review notes.
- Gov notes for any optional Service-only or AI-driven features.
