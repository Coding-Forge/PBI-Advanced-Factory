# Module 9: Monitoring, Administration, and Governance

## Module summary

This module teaches platform owners and support teams how to monitor Power BI adoption, troubleshoot operational issues, review tenant controls, and govern production workloads. It covers usage metrics, refresh history, tenant settings, gateway monitoring, activity logs, admin monitoring, capacity metrics, Purview, DLP, and support operating models.

## Learning objectives

By the end of this module, learners will be able to:

- Interpret usage metrics for reports and Apps.
- Troubleshoot refresh failures using refresh history and data source settings.
- Review tenant settings that affect sharing, export, certification, and external access.
- Inspect gateway status and data source mappings.
- Explain activity logs and audit log requirements.
- Explain admin monitoring workspace and capacity metrics availability.
- Review Purview and DLP integration considerations.
- Build an operations runbook for production Power BI assets.
- Identify Azure Government validation needs for admin, audit, capacity, Purview, and DLP capabilities.

## Feature availability

| Activity logs and audit logs | Verify for Gov | Requires admin permissions and audit configuration. |
| Admin monitoring workspace | Verify for Gov | Availability can vary by cloud and tenant. |
