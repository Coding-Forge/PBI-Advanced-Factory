# Learner Guide

## What you will learn

You will learn how to monitor Power BI content after deployment, troubleshoot refresh and gateway issues, review key tenant governance settings, and build an operations runbook for production support.

## Scenario

Contoso Advanced Manufacturing has published a Power BI App for business users. The BI team needs to monitor adoption, respond to refresh failures, validate gateway health, and document support ownership.

## Prerequisites

- Power BI Service access.
- A workspace with published report and semantic model.
- Optional admin, gateway, capacity, or Purview permissions for advanced labs.

## Azure Government readiness

Usage metrics and refresh history are generally **Gov-ready**. Activity logs, audit logs, admin monitoring workspace, capacity metrics, Purview, and DLP are **Verify for Gov**.

## Power BI project format

Operational changes should refer back to PBIP source artifacts in git. PBIX files are optional generated artifacts and should not be treated as the source of record.

## Tasks

1. Review usage metrics.
2. Troubleshoot refresh history.
3. Review tenant settings conceptually or hands-on.
4. Inspect gateway status where available.
5. Review optional activity logs, admin monitoring, capacity metrics, Purview, and DLP.
6. Complete an operations runbook.

## Validate your work

Your completed work should include:

- Usage/adoption observations.
- Refresh troubleshooting notes.
- Tenant setting review notes.
- Gateway monitoring notes.
- Optional admin/capacity/Purview validation notes.
- Completed operations runbook draft.
