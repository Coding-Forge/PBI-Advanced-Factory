# Module 10: Premium, Fabric, and Capacity-Aware Architecture

## Module summary

This module explains advanced architecture choices for Power BI Premium, Fabric capacity, large semantic models, XMLA endpoints, paginated reports, Direct Lake, OneLake, Lakehouse/Warehouse integration, Semantic Link, autoscale, and capacity monitoring.

## Learning objectives

By the end of this module, learners will be able to:

- Compare Power BI Pro, Premium Per User, Premium capacity, and Fabric capacity scenarios.
- Explain when large semantic model settings are relevant.
- Explain XMLA endpoint use cases and validation requirements.
- Describe paginated report use cases.
- Explain Direct Lake, OneLake, Lakehouse, Warehouse, and Semantic Link at an architectural level.
- Interpret capacity metrics and throttling concepts.
- Identify Azure Government validation needs for Premium, Fabric, Direct Lake, XMLA, paginated reports, autoscale, and capacity metrics.
- Choose a Gov-safe alternate architecture when Fabric features are unavailable.
