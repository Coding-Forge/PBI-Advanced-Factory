# Learner Guide

## What you will learn

You will learn a practical process for diagnosing and improving Power BI performance across reports, DAX, models, Power Query, and refresh behavior.

## Scenario

Contoso Advanced Manufacturing has a report that users describe as "slow." Before changing anything, you will measure performance, identify likely causes, optimize in focused steps, and validate improvement.

## Prerequisites

- Power BI Desktop
- A PBIP report using prior module artifacts
- Basic understanding of model design, DAX, visuals, and Power Query

## Azure Government readiness

The required labs are **Gov-ready** because they use Power BI Desktop features. DAX Studio, VertiPaq Analyzer, Service-side incremental refresh, and capacity metrics are **Verify for Gov**.

## Power BI project format

Save report and model work as PBIP projects. PBIP is the source-controlled format for this workshop. PBIX can be generated later if a packaged file is needed.

## Tasks

1. Measure report performance with Performance Analyzer.
2. Identify model size and cardinality issues.
3. Optimize visuals and report page layout.
4. Optimize a DAX measure.
5. Review aggregation table design.
6. Prepare incremental refresh policy.
7. Compare results against benchmark targets.

## Validate your work

Your completed work should include:

- Performance Analyzer observations.
- At least one visual optimization.
- At least one model-size or cardinality recommendation.
- At least one optimized DAX measure.
- Aggregation table design notes.
- Incremental refresh policy notes.
- Gov validation notes for optional tools and Service features.
