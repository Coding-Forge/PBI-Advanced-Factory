# Module 6: Advanced Analytics and AI-Assisted Insights

## Module summary

This module introduces advanced analytical visuals and AI-assisted experiences in Power BI while clearly separating Gov-ready capabilities from features that require tenant, cloud, licensing, data residency, or preview validation.

## Learning objectives

By the end of this module, learners will be able to:

- Build what-if parameter scenarios.
- Explain when decomposition tree, key influencers, forecasting, and anomaly detection are appropriate.
- Identify non-AI alternatives for Gov-safe delivery.
- Explain Python and R visual prerequisites and governance concerns.
- Describe Azure Machine Learning integration considerations.
- Explain Copilot in Power BI/Fabric conceptually and identify availability constraints.
- Document feature availability for commercial and Azure Government delivery.

## Feature availability

| Feature | Status | Delivery note |
|---|---|---|
| What-if parameters | Gov-ready | Core Desktop modeling/reporting feature. |
| Decomposition tree | Verify for Gov | Validate visual availability and tenant settings. |
| Forecasting | Verify for Gov | Validate visual support, data residency, and tenant policy. |
| Anomaly detection | Verify for Gov | Validate Service/Desktop parity and tenant support. |
| Key influencers | Verify for Gov | AI visual availability can vary by sovereign cloud. |
| Python/R visuals | Verify for Gov | Depends on Desktop configuration, package policy, and Service support. |
| Azure Machine Learning integration | Verify for Gov | Depends on Azure cloud, region, network, identity, and workspace configuration. |
| Copilot in Power BI/Fabric | Commercial-focused / Verify for Gov | Treat as conceptual unless confirmed in the target tenant. |
