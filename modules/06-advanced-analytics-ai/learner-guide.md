# Learner Guide

## What you will learn

You will learn how to add advanced analytical experiences to Power BI reports and how to decide when AI-assisted features are appropriate, available, and governed.

## Scenario

Contoso Advanced Manufacturing wants to understand sales drivers, test margin scenarios, identify unusual trends, and evaluate where AI-assisted features could help users explore data faster.

## Prerequisites

- Power BI Desktop
- A PBIP report/model from earlier modules
- Basic report authoring and DAX knowledge

## Azure Government readiness

The what-if parameter lab is **Gov-ready**. Decomposition tree, forecasting, anomaly detection, key influencers, Python/R visuals, Azure ML integration, and Copilot are **Verify for Gov** or **Commercial-focused** and should be optional unless validated.

## Power BI project format

Save report work as a PBIP project. PBIP is the source-controlled format for this workshop. PBIX can be generated from PBIP later if a packaged file is needed.

## Tasks

1. Build a what-if parameter scenario.
2. Use or review decomposition tree for driver analysis.
3. Use or review forecasting and anomaly detection.
4. Use or review key influencers.
5. Review Python/R visual governance.
6. Review Azure ML integration considerations.
7. Review Copilot concepts and availability constraints.
8. Document Gov-safe alternate approaches.

## Validate your work

Your completed work should include:

- A working what-if parameter.
- Scenario measures that respond to parameter selection.
- Notes on which advanced/AI visuals are available in the delivery tenant.
- A Gov-safe alternate approach for each unavailable AI feature.
- Clear feature availability labels.
