# Module 11: Automation, DevOps, and Lifecycle Management

## Module summary

This module teaches repeatable lifecycle management for Power BI solutions using PBIP, source control, deployment checklists, external tools, REST APIs, PowerShell, service principals, and conceptual CI/CD patterns.

## Learning objectives

By the end of this module, learners will be able to:

- Explain why PBIP is the source-controlled format for this workshop.
- Review PBIP project structure.
- Use git to track Power BI report and semantic model changes.
- Explain Tabular Editor and ALM Toolkit use cases.
- Explain REST API, PowerShell, and service principal automation patterns.
- Describe Fabric workspace Git integration and its availability constraints.
- Design conceptual Azure DevOps and GitHub Actions CI/CD flows.
- Identify Azure Government validation needs for APIs, service principals, XMLA, Git integration, and automation platforms.
