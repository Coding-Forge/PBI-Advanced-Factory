# Learner Guide

## What you will learn

You will learn how to manage Power BI content through PBIP, git, deployment checklists, optional external tools, and conceptual automation workflows.

## Scenario

Contoso Advanced Manufacturing wants repeatable development and deployment for Power BI content. The team needs source control, reviewable changes, environment promotion, and a path toward automation that works for commercial and Azure Government customers.

## Prerequisites

- Git installed.
- PBIP report/model from earlier modules.
- Basic understanding of branches, commits, and pull requests.
- Optional access to Power BI APIs, external tools, or CI/CD platform.

## Azure Government readiness

PBIP and local git workflows are **Gov-ready**. REST APIs, PowerShell, service principals, XMLA, Fabric Git integration, Azure DevOps, and GitHub Actions are **Verify for Gov** or **Commercial-focused / Verify for Gov**.

## Tasks

1. Review PBIP structure.
2. Track PBIP changes with git.
3. Review Tabular Editor workflow where available.
4. Review ALM Toolkit comparison where available.
5. Review optional REST API deployment.
6. Review optional PowerShell administration.
7. Review optional service principal authentication.
8. Review optional Fabric workspace Git integration.
9. Review conceptual Azure DevOps and GitHub Actions pipelines.
10. Complete the deployment checklist.

## Validate your work

Your completed work should include:

- PBIP structure notes.
- Git workflow notes.
- Deployment checklist.
- Gov validation notes for each optional automation path.
- Conceptual CI/CD flow selected for the customer environment.
