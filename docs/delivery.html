Delivery Options

Scoped to fit a 1-day briefing or a 3 to 5-day deep dive.

The number of days is fixed; the hours per day and the exact module mix are refined during a scoping call to match the audience and cloud.

Formats

1 day

Focused workshop

A single-day session highlighting the modules most relevant to the audience. May need to be refined to fit the available time.

3 days

Advanced track

Modules 1–7 delivered across three days, 10am–3pm with a 30-minute midday break, covering modeling through security.

5 days

Full enterprise lifecycle track

Modules 1–12 across five days, extending the advanced track with deployment, governance, capacity, DevOps, and a capstone project.

The number of days is fixed per format; the exact module mix and hours are refined during a scoping call to fit the audience and available time.

Sample 3-day agenda

Each day runs 10am–3pm with a 30-minute break around noon.

  • Day 1

    Module 1: Advanced Semantic Modeling · Module 2: Advanced DAX

  • Day 2

    Module 3: Advanced Power Query · Module 4: Report Design & UX

  • Day 3

    Module 5: Performance Optimization · Module 6: Advanced Analytics & AI · Module 7: Security Design

Sample 5-day agenda

Builds on the 3-day advanced track, then adds enterprise deployment and lifecycle modules across two more days.

  • Day 1

    Module 1: Advanced Semantic Modeling · Module 2: Advanced DAX

  • Day 2

    Module 3: Advanced Power Query · Module 4: Report Design & UX

  • Day 3

    Module 5: Performance Optimization · Module 6: Advanced Analytics & AI · Module 7: Security Design

  • Day 4

    Module 8: Service Enterprise Deployment · Module 9: Monitoring, Administration & Governance

  • Day 5

    Module 10: Premium, Fabric & Capacity-Aware Architecture · Module 11: Automation & DevOps · Capstone
