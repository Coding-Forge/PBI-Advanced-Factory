# Environment Setup Guide

Use this guide to prepare a delivery environment for the Power BI Advanced Factory workshop.

## Required local software

- Power BI Desktop
- Git
- Modern browser supported by Power BI Service
- Text editor or IDE for markdown and PBIP source review

## Optional local software

Validate customer policy before using:

- DAX Studio
- Tabular Editor
- ALM Toolkit
- Power BI Report Builder
- Python or R runtime
- PowerShell modules for Power BI

## Required repository setup

1. Clone or copy the workshop repository.
2. Confirm the correct path.
3. Confirm module and lab folders are present.
4. Confirm synthetic data files are present.
5. Confirm PBIP starter files when they are created.

## Optional Service setup

- Training workspace
- Instructor Admin role
- Learner Contributor role if hands-on publishing is allowed
- Test users or groups for RLS
- Gateway if required
- App distribution permissions
- Endorsement/certification permissions if required

## Azure Government validation

Before Gov delivery, validate:

- Tenant cloud and licensing
- Allowed connectors
- Gateway/network path
- Identity format for RLS
- External tool policy
- Sensitivity labels and Purview
- Fabric feature availability
- Copilot/AI feature availability
- REST API/service principal support
- CI/CD platform policy
