# Learner Workbook

Use this workbook as the learner-facing guide across the full workshop. Module-specific details live in each module's `learner-guide.md` and lab `README.md`.

## Workshop objective

Build advanced Power BI skills across modeling, DAX, Power Query, report UX, performance, security, Service deployment, monitoring, capacity architecture, and DevOps.

## Source control standard

All Power BI work should be created as PBIP projects. PBIP is the source-controlled format for this workshop. PBIX files can be generated later when a packaged file is needed.

## Learning path

1. Review the audience, prerequisites, and Azure Government feature labels.
2. Complete Modules 1-11 in sequence.
3. Complete the capstone using the Gov-ready path.
4. Add commercial-enhanced extensions only when the tenant and customer policy are validated.
5. Submit evidence using the capstone validation rubric.

## Learner evidence checklist

- [ ] PBIP source project.
- [ ] Semantic model notes.
- [ ] DAX measure notes.
- [ ] Report screenshots or review notes.
- [ ] RLS test results.
- [ ] Refresh and gateway notes.
- [ ] App/governance notes.
- [ ] Operations runbook.
- [ ] Azure Government readiness notes.
- [ ] Optional extension validation notes.
