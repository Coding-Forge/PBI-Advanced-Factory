Curriculum

12 modules, one connected PBIP project.

Each module builds on the same semantic model and reports, so learners see how modeling choices ripple into performance, security, and deployment decisions later in the week.

Module path

Modules 1–7 form the foundation of a 3-day delivery; modules 8–12 extend into a full enterprise lifecycle track.

  1. 01 · Advanced Semantic Modeling

    Star schema refinement, role-playing dimensions, relationships, and model documentation.

  2. 02 · Advanced DAX

    Variables, iterators, time intelligence, calculation groups, and context transition patterns.

  3. 03 · Advanced Power Query & Data Transformation

    Parameterized queries, function libraries, and query-folding-aware transformations.

  4. 04 · Report Design & UX

    Drillthrough, tooltip pages, bookmarks, navigation, field parameters, hierarchies and drill-down/across, groups, conditional formatting, and accessibility.

  5. 05 · Performance Optimization

    Performance Analyzer-driven tuning, DAX rewrites, and aggregation table design.

  6. 06 · Advanced Analytics & AI-Assisted Insights

    What-if parameters plus a guided review of decomposition trees, forecasting, key influencers, and Azure ML/Copilot options.

  7. 07 · Security Design

    Static and dynamic row-level security, role testing, Build permission, and OLS/sensitivity-label planning.

  8. 08 · Power BI Service Enterprise Deployment

    Workspace design, publishing, refresh and gateways, Apps, and deployment pipelines.

  9. 09 · Monitoring, Administration & Governance

    Usage metrics, refresh history, and tenant settings review.

  10. 10 · Premium, Fabric & Capacity-Aware Architecture

    Licensing and capacity comparisons, XMLA endpoints, Direct Lake, and Capacity Metrics.

  11. 11 · Automation, DevOps & Lifecycle Management

    Git-based PBIP workflows, pull request review practices, and CI/CD concepts.

  12. Capstone · Enterprise-Ready Power BI Solution

    A cumulative project applying modeling, UX, performance, security, and deployment skills to one solution.

What every module includes

Walkthrough tasks

Clear objectives for what to build before diving into detailed steps.

Step-by-step procedure

Explicit ribbon and menu paths, exact settings, and what to check to confirm success.

Knowledge check

A short set of questions with an answer key for self-check or instructor review.

Azure Government note

Each module flags features that are Gov-ready, need tenant verification, or are commercial-only.
