# Power BI Advanced Factory Customer Datasheet

## Overview

Power BI Advanced Factory is a hands-on training program for teams that want to improve how they prepare data, design semantic models, write trusted measures, build interactive reports, and operate Power BI content with enterprise discipline.

The training is designed for report authors, analysts, semantic model developers, BI platform owners, and administrators. The material uses synthetic data and a PBIP-first workflow so learners can practice in a safe, source-controlled project format.

## What participants will learn

| Area | High-level outcome |
|---|---|
| Data preparation | Build cleaner, more maintainable Power Query workflows with parameters, staging queries, reusable functions, and data-quality review. |
| Semantic modeling | Convert flat reporting exports into reusable fact and dimension models with clear relationships and date tables. |
| DAX measures | Create consistent business measures, time intelligence, rankings, and reusable calculation patterns. |
| Report experience | Build reports that guide users with drillthrough, tooltips, bookmarks, navigation, field parameters, mobile layout, and accessibility checks. |
| Performance | Capture a baseline, identify slow visuals or model issues, and make evidence-based improvements. |
| Analytics scenarios | Add scenario analysis with what-if parameters and evaluate advanced/AI features only when they are available and appropriate. |
| Security | Understand static and dynamic row-level security and how to validate security behavior before production use. |
| Deployment and operations | Review optional Service deployment, refresh, Apps, monitoring, governance, and support practices. |
| Lifecycle management | Understand how PBIP and source control support repeatable Power BI development. |

## Three-day delivery focus

The standard shortened delivery covers **Modules 1-7**:

| Module | Plain-language description |
|---|---|
| Module 1: Advanced Semantic Modeling | Build a strong model foundation so reports are easier to maintain and measures behave correctly. |
| Module 2: Advanced DAX | Create trusted metrics and reusable calculations for sales, margin, targets, time intelligence, and ranking. |
| Module 3: Advanced Power Query | Prepare data using source parameters, staging queries, reusable cleanup functions, and error review. |
| Module 4: Report Design and UX | Design report pages that are easier for business users to navigate and understand. |
| Module 5: Performance Optimization | Learn how to measure and improve report/model performance instead of guessing. |
| Module 6: Advanced Analytics and AI-Assisted Insights | Use scenario analysis and discuss advanced/AI features with appropriate validation. |
| Module 7: Security Design | Apply and test row-level security patterns for controlled data access. |

## Optional extension modules

| Optional module | Why customers request it |
|---|---|
| Module 8: Service Enterprise Deployment | Publishing, refresh, workspaces, Apps, and governed distribution. |
| Module 9: Monitoring, Administration, and Governance | Usage review, refresh troubleshooting, tenant settings, and support/runbook practices. |
| Module 10: Premium, Fabric, and Capacity Architecture | Capacity planning, Premium/Fabric considerations, and architecture tradeoffs. |

## Delivery style

- Short presentation segments introduce the concept.
- Guided labs let participants apply the concept immediately.
- Each day includes checkpoints and Q&A.
- Optional or tenant-dependent features are clearly identified before hands-on use.
- Learners can use Markdown instructions or the HTML lab site.

## Customer prerequisites

| Requirement | Notes |
|---|---|
| Power BI Desktop | Required for core hands-on labs. |
| Workshop files | Provided as PBIP projects, lab instructions, and synthetic CSV data. |
| Power BI Service workspace | Optional for deployment, refresh, security-in-Service, Apps, and monitoring labs. |
| Tenant validation | Required before making Fabric, Copilot, deployment pipelines, XMLA, APIs, or external tools hands-on. |

## Expected takeaways

Participants leave with:

- A working Power BI project built from synthetic data.
- A clearer understanding of model design, DAX, Power Query, UX, performance, and security.
- Practical patterns they can reuse in customer or internal reporting projects.
- A list of tenant-dependent features that should be validated before production adoption.
