# Commercial Delivery Notes

Use these notes when delivering in a validated commercial tenant.

## Commercial-enhanced options

Commercial delivery may include optional hands-on extensions when licensing, capacity, tenant settings, and customer policy allow:

- Fabric workspace Git integration
- Direct Lake
- OneLake, Lakehouse, and Warehouse integration
- Semantic Link
- Copilot in Power BI/Fabric
- AI visuals
- Deployment pipelines
- REST API deployment
- Service principal automation
- XMLA workflows
- Capacity metrics app

## Required controls

- Keep PBIP as the source of record.
- Validate optional features before delivery.
- Avoid customer-sensitive data in AI/Copilot demos.
- Require human review of AI-generated content.
- Document fallback paths for Gov or restricted environments.
- Record deployment and validation evidence.

## Delivery note

Commercial availability does not automatically mean a feature is approved for a specific customer. Always validate customer policy, licensing, security, and data handling requirements.
