Novice-friendly how-to guide

Create a what-if parameter

  1. Select Modeling > New parameter > Numeric range.
  2. Name the parameter Margin Adjustment %.
  3. Set minimum, maximum, and increment values from the lab.
  4. Keep the generated slicer.
  5. Use the generated parameter measure inside an adjusted-margin DAX measure.

Use an advanced visual only when available

  1. Confirm the visual is available in the target tenant.
  2. Add the visual to a duplicate or practice page.
  3. Add the measure to analyze and the dimensions to explain it.
  4. Document what the visual suggests and what it does not prove.

Create a Gov-safe fallback

  1. Use a matrix, bar chart, Top N filter, rolling average, or threshold measure.
  2. Document how the fallback answers the same business question.
  3. Mark AI or external runtime features as optional unless validated.

Detailed step-by-step procedure

  1. Start with the Gov-ready core.

    Open the report PBIP and choose a page where margin or sales scenario analysis makes sense.

  2. Create a what-if parameter.

    In Power BI Desktop, create a parameter named Margin Adjustment %. Use a reasonable range such as -10 to 20 with an increment such as 1.

  3. Create adjusted measures.

    Create a measure that applies the selected parameter to Gross Margin or Sales Amount. Use a clear name such as Adjusted Gross Margin.

  4. Add scenario visuals.

    Add the parameter slicer, a base metric card, an adjusted metric card, and a comparison visual. Confirm visuals update when the slicer changes.

  5. Evaluate decomposition tree.

    If available, add the visual and use Sales Amount or Gross Margin as the analyzed metric. Add dimensions such as Territory, Product Category, Customer Type, and Segment. If unavailable, use a matrix and drillthrough instead.

  6. Evaluate forecasting/anomaly options.

    If available, add forecasting or anomaly detection to a supported line chart. If unavailable, create rolling averages, prior-period comparison, or DAX threshold flags.

  7. Evaluate key influencers.

    If available, test the visual with a clear outcome and explanatory fields. Discuss interpretation limits. If unavailable, use ranking and Top N visuals.

  8. Review Python/R and Azure ML.

    Do not add these unless runtimes, packages, Service support, network, identity, and data residency are validated. Use native visuals or static scored sample outputs as the fallback.

  9. Review Copilot conceptually.

    If Copilot is not validated, use the conceptual section only. Explain that AI output requires human review and cannot be treated as authoritative.

  10. Document feature status.

    For every advanced or AI-assisted feature, record Gov-ready, Verify for Gov, or Commercial-focused and list the fallback used.

Answer key

Show what-if parameter DAX pattern

Power BI may generate slightly different names for the parameter table and selected-value measure. Adjust names to match your model.

// Generated or equivalent selected value measure
Margin Adjustment % Value =
SELECTEDVALUE ( 'Margin Adjustment %'[Margin Adjustment %], 0 )

Adjusted Gross Margin =
VAR AdjustmentRate =
    DIVIDE ( [Margin Adjustment % Value], 100 )
RETURN
    [Gross Margin] * ( 1 + AdjustmentRate )

Adjusted Gross Margin % =
DIVIDE ( [Adjusted Gross Margin], [Sales Amount] )

Margin Scenario Title =
VAR Adjustment =
    FORMAT ( DIVIDE ( [Margin Adjustment % Value], 100 ), "0%" )
RETURN
    "Margin scenario: " & Adjustment
