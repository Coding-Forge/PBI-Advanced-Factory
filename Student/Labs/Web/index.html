Before you begin

  • Install Power BI Desktop.
  • Confirm access to raw.githubusercontent.com.
  • Save your work as a Power BI file (PBIX or PBIP); Lab 11 covers PBIP for Git-based source control.
  • Use the Gov-ready path unless optional features are validated.

Branding

Edit scripts\delivery-config.js to set the customer name, logo, badge, and accent colors. Alternate configs can be tested with the brandConfig query-string parameter.
