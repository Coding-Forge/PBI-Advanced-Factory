Lab 4 - Guided report experience

Report Design and UX

Design audience-focused report pages with clear filters, drillthrough, tooltips, bookmarks, navigation, field parameters, conditional formatting, mobile layout, and accessibility review.

Advanced authoringDeliverable: Interactive report pagesPBIP-first

  • Drillthrough details
  • Report page tooltip
  • Bookmarks and navigation
  • Field parameters and selectors
  • Mobile and accessibility review

Walkthrough tasks

Plan audience pages and filters

  • Define executive, analyst, and operational/detail page purposes.
  • Place slicers and page filters consistently so users understand report context.

Add drillthrough and tooltips

  • Create Customer Detail drillthrough with Back navigation.
  • Create and assign a compact Sales Tooltip page.

Add bookmarks and navigation

  • Use Show/Hide or Reset bookmarks with intentional Data, Display, and Current page settings.
  • Add page navigation buttons or a navigator with consistent labels.

Add guided metric exploration

  • Create Metric Parameter and optional Dimension Parameter field parameters.
  • Compare the native field parameter to a disconnected Metric Selector SWITCH pattern.

Add target-driven formatting

  • Create the optional Margin Target disconnected table and measures if time allows.
  • Use conditional formatting with documented thresholds and non-color cues.

Create mobile and accessible experiences

  • Build a mobile layout with prioritized visuals and touch-friendly sizing.
  • Add alt text, tab order, contrast checks, descriptive titles, and keyboard-friendly design.

Novice-friendly how-to guide

Plan audience pages and filters

  1. Write the audience and decision question for each page.
  2. Use executive, analyst, and operational/detail purposes to decide visuals.
  3. Place slicers consistently and label them clearly.
  4. Avoid hidden or conflicting filter states.

Create a drillthrough page

  1. Add a page named Customer Detail.
  2. Add DimCustomer[CustomerName] to the Drill-through field well.
  3. Add customer visuals and a Back button.
  4. Test by right-clicking a customer on another page.

Create a tooltip page

  1. Add a page and set page type to Tooltip.
  2. Build compact KPIs or a trend.
  3. Assign the tooltip page to a main visual.

Create a field parameter

  1. Select Modeling > New parameter > Fields.
  2. Name it Metric Parameter.
  3. Select [Sales Amount], [Gross Margin], [Gross Margin %], and [Quantity].
  4. Add the generated parameter field to a visual.

Review accessibility

  1. Add descriptive titles and alt text.
  2. Set a logical tab order.
  3. Check contrast and avoid color-only meaning.
  4. Confirm keyboard users can follow the report flow.

Deeper Understanding Challenge

Build a disconnected metric selector

Compare native field parameters with a Power Query selector table and a DAX SWITCH measure.

  1. Create a blank Power Query named Metric Selector.
  2. Use #table to create rows for Sales Amount, Gross Margin, Gross Margin %, and Quantity.
  3. Load the table without relationships.
  4. Create Selected Metric Value using SELECTEDVALUE and SWITCH.
let
    Source =
        #table(
            type table [Metric = text, SortOrder = Int64.Type],
            {
                {"Sales Amount", 0},
                {"Gross Margin", 1},
                {"Gross Margin %", 2},
                {"Quantity", 3}
            }
        )
in
    Source
Selected Metric Value =
VAR SelectedMetric =
    SELECTEDVALUE ( 'Metric Selector'[Metric], "Sales Amount" )
RETURN
    SWITCH (
        SelectedMetric,
        "Sales Amount", [Sales Amount],
        "Gross Margin", [Gross Margin],
        "Gross Margin %", [Gross Margin %],
        "Quantity", [Quantity],
        [Sales Amount]
    )

Detailed step-by-step procedure

  1. Open the report PBIP.

    Start from the model and measures created in earlier labs. Confirm that Sales Amount, Gross Margin, variance, date, customer, product, territory, and segment fields are available.

  2. Create the executive summary page.

    Add KPI cards for Sales Amount, Gross Margin %, Sales Variance, and Quantity. Add a trend visual and one high-level breakdown such as sales by territory.

  3. Plan audience-driven report pages.

    Write the primary audience and decision question for each page. Keep executive, analyst, and operational/detail pages distinct so interactivity reduces cognitive load instead of adding confusion.

  4. Create the analyst exploration page.

    Add slicers for date, territory, product category, and customer type. Add visuals that allow comparison across customer, product, territory, and segment.

  5. Validate slicers and filters.

    Place slicers consistently, use page-level filters where appropriate, and verify users can explain which filters are active before interpreting the visuals.

  6. Create a drillthrough page.

    Add a page named Customer Detail. Add CustomerName to the Drillthrough field well. Add KPI cards, a transaction table, and a Back button. Test drillthrough from a customer visual.

  7. Create a report page tooltip.

    Add a page named Sales Tooltip. Change the page size to Tooltip and enable it as a tooltip page. Add compact KPIs and a small trend visual, then assign it to a visual on the main page.

  8. Add bookmarks and buttons.

    Create a show/hide panel or reset-state interaction. Open the Bookmarks pane, capture the intended state, and check whether Data, Display, and Current Page should be enabled.

  9. Add navigation.

    Add page navigation buttons or a navigator visual. Keep placement consistent across report pages and use plain labels that learners can understand.

  10. Add field parameters.

    Select Modeling > New parameter > Fields. Create a Metric Parameter with approved measures such as Sales Amount, Gross Margin, Gross Margin %, and Quantity. Add the generated parameter field to a visual and use the slicer to switch metrics. Optionally create a Dimension Parameter for Product Category, Territory, and Segment.

  11. Apply conditional formatting.

    Choose one business threshold, such as negative variance or low margin. Apply color/icon formatting and document what the threshold means.

  12. Build the margin target challenge.

    If time allows, create the disconnected Margin Target table and DAX measures for selected target, variance to target, status, and status color. Use the status alongside conditional formatting so color is not the only cue.

  13. Create mobile layout.

    Open Mobile layout view. Add only the highest-value visuals, enlarge touch targets, and avoid dense tables unless necessary.

  14. Run accessibility review.

    Add alt text, review tab order, check contrast, verify visual titles, and ensure color is not the only way meaning is communicated.
