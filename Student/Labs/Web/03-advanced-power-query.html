Novice-friendly how-to guide

Create a Power Query parameter

  1. Open Transform data to launch Power Query.
  2. Select Manage Parameters > New Parameter.
  3. Enter the exact parameter name, data type, and current value from the lab.
  4. Select OK and use the parameter in source steps instead of hard-coded paths.

Append queries

  1. In Power Query, select Home > Append Queries > Append Queries as New.
  2. Choose Three or more tables.
  3. Add each raw monthly query in order.
  4. Name the result stg_OrdersCombined.
  5. Check that columns line up and data types are consistent.

Disable load for staging queries

  1. Right-click each raw or staging query.
  2. Clear Enable load.
  3. Leave final model-ready queries enabled.
  4. Select Close & Apply when the query set is ready.

Detailed step-by-step procedure

  1. Open the PBIP project and Power Query.

    Open the current PBIP solution. Select Transform data to open Power Query Editor.

  2. Create a raw data base parameter.

    Create a text parameter named RawDataBaseUrl with value https://raw.githubusercontent.com/Coding-Forge/PBI-Advanced-Factory/main/data/. This makes the Web source pattern easier to maintain.

  3. Load monthly order files.

    Use New Source > Web for each monthly order CSV. Name the raw queries raw_Orders_2026_01, raw_Orders_2026_02, and raw_Orders_2026_03.

  4. Add source lineage.

    In each raw monthly query, add a custom column named SourceFile with the file name, such as orders-2026-01.csv. This helps identify which file produced each row.

  5. Append the monthly queries.

    Use Append Queries as New and append the three monthly order queries. Rename the result stg_OrdersCombined.

  6. Create the final fact query.

    Reference stg_OrdersCombined and name the new query fact_Orders. Apply explicit data types for OrderId, OrderDate, ProductCode, Quantity, UnitPrice, and SalesChannel.

  7. Create a cleanup function.

    Create fn_CleanText to trim and clean nullable text values. Invoke it on CustomerName and other text columns where whitespace or inconsistent capitalization exists.

  8. Identify bad data.

    Use column quality/profile and type-conversion errors to find the intentional bad date and bad quantity in the March file. Create an error review query before removing or replacing rows.

  9. Load reference data.

    Use the Web connector for product-category-map.csv. Merge it into fact_Orders on ProductCode or keep it as a dimension/reference table, depending on the lab design.

  10. Prepare for incremental refresh.

    Create DateTime parameters named RangeStart and RangeEnd. Filter the final fact query on OrderDate using those parameters. Document Service-side incremental refresh as Verify for Gov.

Show Power Query M patterns

These snippets show the intended M patterns. Your generated step names may differ depending on how you clicked through Power Query.

// Parameter value
RawDataBaseUrl = "https://raw.githubusercontent.com/Coding-Forge/PBI-Advanced-Factory/main/data/"

// Example Web source pattern
Source =
    Csv.Document(
        Web.Contents(RawDataBaseUrl & "monthly-orders/orders-2026-01.csv"),
        [Delimiter = ",", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]
    )

PromotedHeaders =
    Table.PromoteHeaders(Source, [PromoteAllScalars = true])

WithSourceFile =
    Table.AddColumn(
        PromotedHeaders,
        "SourceFile",
        each "orders-2026-01.csv",
        type text
    )

// Append pattern
stg_OrdersCombined =
    Table.Combine({
        raw_Orders_2026_01,
        raw_Orders_2026_02,
        raw_Orders_2026_03
    })

// Text cleanup function
(inputText as nullable text) as nullable text =>
let
    Result =
        if inputText = null then
            null
        else
            Text.Proper(Text.Trim(Text.Clean(inputText)))
in
    Result

// Final type pattern
TypedOrders =
    Table.TransformColumnTypes(
        stg_OrdersCombined,
        {
            {"OrderId", Int64.Type},
            {"OrderDate", type date},
            {"CustomerName", type text},
            {"ProductCode", type text},
            {"Quantity", Int64.Type},
            {"UnitPrice", Currency.Type},
            {"SalesChannel", type text},
            {"SourceFile", type text}
        }
    )

// Incremental refresh filter pattern
FilteredRows =
    Table.SelectRows(
        TypedOrders,
        each [OrderDate] >= Date.From(RangeStart)
            and [OrderDate] < Date.From(RangeEnd)
    )
