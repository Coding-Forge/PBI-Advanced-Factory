# Capstone Gov-Ready Path

This is the required baseline path for Azure Government or restricted customer environments.

## Required capabilities

- PBIP source-controlled development.
- Import-mode semantic model unless DirectQuery is validated.
- Star schema model.
- Advanced DAX measures.
- Core report UX features: drillthrough, tooltip pages, bookmarks, buttons, conditional formatting, mobile layout.
- Static and dynamic RLS.
- Desktop role testing.
- Service publishing where a training workspace is available.
- Scheduled refresh where supported.
- Gateway requirements documented where applicable.
- Power BI App distribution where available.
- Endorsement checklist.
- Operations runbook.

## Excluded from required path unless validated

- Fabric workspace Git integration.
- Direct Lake.
- OneLake, Lakehouse, or Warehouse.
- Copilot.
- AI visuals.
- Python/R visuals.
- Azure ML integration.
- Deployment pipelines.
- REST API deployment.
- Service principal automation.
- XMLA external-tool workflows.
- Capacity metrics app.

## Required documentation

For every excluded feature, document the learning goal and Gov-safe alternate path.
