# Capstone Validation Rubric

Use this rubric to evaluate learner submissions.

| Area | Meets expectations | Needs improvement |
|---|---|---|
| PBIP source control | Power BI work is saved as PBIP and source is reviewable in git. | Work is PBIX-only or source files are missing. |
| Semantic model | Model uses clear fact/dimension structure and relationships are intentional. | Model is flat, ambiguous, or has unclear relationships. |
| DAX | Measures are correct, formatted, branched, and validated at multiple grains. | Measures are duplicated, incorrect, or not validated. |
| Report UX | Report includes purposeful pages, drillthrough, tooltip, bookmarks, conditional formatting, and mobile layout. | Report lacks guided interaction or has cluttered pages. |
| Accessibility | Alt text, contrast, tab order, titles, and non-color cues are reviewed. | Accessibility is not documented or obvious issues remain. |
| Security | Static and dynamic RLS are implemented and tested. | RLS is missing, untested, or identity mapping is unclear. |
| Service deployment | Publishing, refresh, gateway, App, and access are completed or documented as instructor demo/blocked. | Service path is undocumented. |
| Governance | Endorsement checklist and access decisions are documented. | Governance evidence is incomplete. |
| Monitoring and operations | Operations runbook, usage/refresh review, and support ownership are documented. | Support model is unclear. |
| Azure Government readiness | Commercial-only and validation-dependent features are labeled with Gov-safe alternatives. | Gov/commercial differences are not identified. |
| Optional extensions | Optional Fabric/Git/Copilot/API features are validated before use. | Optional features are assumed available without validation. |

## Scoring guidance

| Rating | Description |
|---|---|
| Complete | Meets expectations in all required Gov-ready areas. |
| Complete with notes | Meets required areas but has minor documentation or validation gaps. |
| Incomplete | Missing one or more required Gov-ready areas. |
| Extension complete | Includes validated commercial-enhanced extensions with fallback documentation. |

## Required evidence

- PBIP project location.
- Model diagram or relationship screenshot.
- Measure list or DAX reference.
- Report page screenshots or review notes.
- RLS test results.
- Service deployment evidence or documented reason for demo-only mode.
- Refresh/gateway notes.
- App/governance notes.
- Operations runbook.
- Azure Government readiness notes.
